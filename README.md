# FitApp

Fitness tracking application built with a modern Full-Stack TypeScript architecture.

## 🛠️ Tech Stack

**Frontend (Mobile):**
- React Native
- Expo (SDK 54)
- Expo Router (File-based routing)
- TypeScript

**Backend (API):**
- Node.js & Express
- TypeScript
- ts-node & nodemon
- PostgreSQL
- TypeORM

## ✨ Features
- Food tracking
- Macro tracking
- Water tracking
- Daily goals
- Meal editing
